# Website My Personal Homepage Jonathan Tulle
Website ini digunakan sebagai website portofolio pribadi yang di dalamnya terdapat 4 halaman (Home,Gallery,Blog, dan Contact). 

Untuk melihat pembaharuan atau update terbaru website My Personal Hompage saya silahkan untuk di klik bagian folder (Mid.Project), folder Mid.Project khusus dibuat untuk memenuhi tugas Mid.Project-Personal.Homepage. Isi folder Mid.Project merupakan update atau kelanjutan dari tugas Project.01-HTML 2026 (yang hanya untuk html saja) di dalam folder Mid.Project sudah ditambahkan css (style.css) dan javascript (script.js) serta ada pembaharuan untuk file html.
